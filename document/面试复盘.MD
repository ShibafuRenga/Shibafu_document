# 面试复盘与提升计划

## 本次暴露的问题（归类）

1. **概念只到关键词**：会说「标记清除 / wrap / 虚拟栈」，但答不上「根从哪来」「调用具体怎么走」。
2. **用过但没下沉一层**：MaskableGraphic、UIParticle 只停留在「能画出来」，说不清顶点/Mesh/CanvasRenderer 链路。
3. **做过但没想 Why**：工作里「觉得 ok 就做了」，面试问问题与总结就空。
4. **过度信 AI**：Spine 形变被带偏，没回到「骨 → 蒙皮权重 → 顶点」基本模型去验。

一句话：不是简历写太深，是**每项只薄薄盖了一层**，深挖就穿。

---

## 提升原则（比「多看书」重要）

| 原则 | 做法 |
|------|------|
| **下沉一层** | 每个简历关键词，至少能讲到「调用链 / 数据结构 / 一处源码」 |
| **先物理模型，再工具名词** | Spine 先骨+权重+顶点；GC 先根集合；再谈 xLua/GPU |
| **AI 只当草稿** | AI 说完必须用文档/源码证伪；说不清就标「未验证」 |
| **Why 日记** | 每周 1 个工作决策写：问题 → 方案 → 为什么不选另一种 → 事后对不对 |
| **讲具体** | 禁止只说「把顶点搞进去」；要说：谁生成 mesh、哪些属性、谁 SetMesh、何时 Rebuild |

## 四周小计划（顺着这次挂点）

### 第 1 周：xLua 一条调用链（必啃）

目标：闭眼说出 `lua → transform.position`（或任意 wrap 属性）全过程。

建议跟读顺序（按你们工程实际类名微调）：

1. Lua 里 `xxx.transform.position = ...` 或 get  
2. 对应 `XxxWrap.cs` 里注册的 getter/setter  
3. 虚拟栈：参数怎么 push / get / 返回值怎么回 Lua  
4. 最终调到 Unity `Transform` 的哪次 C# 调用  

交付物：自己画一张 **10 步以内** 的流程图，贴在本文件下面「附录」。

自测题：

- wrap 文件是干什么的？谁生成的？  
- 虚拟栈和 C# 栈是一回事吗？  
- get position 和 set position 在栈上差在哪？  
- 报错 `invalid arguments` 通常卡在哪一层？

### 第 2 周：Lua GC 补全「根」

标记清除你会了，补这三块即可应付大部分面试：

1. **根从哪来**：栈上活着的对象、全局表 `_G`、registry、被 C#/宿主钉住的引用（xLua 里还有翻译对象、delegate 等）  
2. **一次 GC 周期**：标记 →（可能的原子/增量）→ 清除；和「停顿」的关系一句话  
3. **和 Unity 的交界**：Lua 对象引用 C# 对象时，谁防泄漏？（需结合 xLua 的翻译/释放，读一小节官方 FAQ 即可）

自测题：面试官问「根哪来的」——你要能答：**当前调用栈 + 全局/registry + 宿主持有的引用**，并举一个例子。

### 第 3 周：UGUI 画一个「真具体」

选你简历上写过的 **MaskableGraphic 或 SymbolBlur 或 UIParticle**，按代码念：

1. `OnPopulateMesh` / BakeMesh 谁调、何时调  
2. `VertexHelper` 里顶点有哪些通道（pos/uv/color…）  
3. mesh 怎么到 `CanvasRenderer.SetMesh`  
4. Mask 相关：stencil / clip 你用到哪一层（说不清就说「用了 Maskable 基类能力，细节我再对一下」——比瞎编好）

交付物：对某一个类，写 **半页「从脏标记到屏幕」**，禁止空话。

### 第 4 周：Spine 从第一性原理重学

先强制建立正确模型（可写在纸上）：

1. **骨骼**：局部变换（平移/旋转/缩放），组成层级，算出世界矩阵  
2. **网格**：真正画的是 **顶点**；每个顶点带 **骨骼索引 + 权重**（蒙皮）  
3. **RegionAttachment**：可以看成带骨绑定的四边形（4 顶点），不是「只扭四边而顶点不动」  
4. **MeshAttachment / Deform**：更多顶点 + 可选变形时间轴  

再回去看 GPUSpine：你 bake 的是骨矩阵时间线还是变形后的顶点，自己用代码对上。

AI 规则：涉及骨骼/蒙皮，**先画图再问 AI**；AI 结论必须能指到 Spine 运行时某段逻辑。

## 日常习惯（可持续）

### 1. 「简历条目 → 三件套」卡片

每个会写进简历的点，固定准备：

```text
是什么（1 句）
在我项目里怎么走（5～8 步或类名）
一个坑 / 一次取舍（Why）
```

本周优先卡片：xLua 调用、Lua GC 根、MaskableGraphic、Spine 蒙皮、状态机+Command 一次真实链路。

### 2. 工作 Why 周记（30 分钟/周）

模板：

- 现象/需求：  
- 我怎么做的：  
- 备选方案：  
- 为什么选这个：  
- 若重来会不会改：  

面试「有什么总结」直接念周记，不要现场编。

### 3. AI 使用红线

- 允许：列提纲、找文件、对比两种 API  
- 禁止：不看代码就接受「Spine 只扭四边形的边」这类几何结论  
- 验收：你能用自己的话讲，并指出「我是在某某函数里看到的」

### 4. 面试答题纪律

被深挖时：

1. 先答到你确定的一层  
2. 不确定就说「这一层我印象是…，细节我没跟到源码」  
3. **不要用更抽象的词糊弄**（面试官最烦「把顶点搞进去就能画」）
